# Asset Placeholders

Put your imported assets here:

- `models/` for GLB/GLTF/FBX conversions
- `textures/` for albedo/normal/roughness/emissive maps
- `audio/` for ambient loops and room tones

Recommended placeholders:

- `models/chandelier.glb`
- `models/ivy_cluster.glb`
- `models/marble_statue.glb`
- `models/vintage_radio.glb`
- `models/neon_sign.glb`
- `models/glass_partition.glb`
- `models/wood_cabinet.glb`
- `models/leather_couch.glb`

The prototype currently uses generated geometry until these models are loaded.
